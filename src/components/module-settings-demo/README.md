# Module Settings Demo
It is a D5-only example module that demonstrates Content panel field types (`divi/text`, `divi/richtext`, `divi/select`, `divi/checkboxes`) under a single **Content** options group. Use it as a sandbox for third-party module settings and `innerContent` patterns.
